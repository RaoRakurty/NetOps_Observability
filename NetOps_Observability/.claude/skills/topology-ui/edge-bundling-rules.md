# Edge Bundling Rules

## Purpose

Reduce visual noise in large topologies.

## Bundle when

- multiple physical links exist between same devices
- LAG members connect same peers
- redundant WAN circuits connect same sites
- many access links connect into a distribution block
- many cloud workloads connect to same service/subnet

## Show at zoomed-out level

Examples:
- 4x100G
- LAG 23
- 2 WAN circuits
- 18 access links
- 42 workloads

## Expand on demand

On click or zoom-in:
- show member interfaces
- show per-link status
- show utilization
- show errors
- show evidence
