# Semantic Zoom

## Zoom levels

Global:
- regions
- sites
- clouds
- WAN paths

Site:
- buildings
- zones
- branch/DC boundaries

Fabric:
- spine
- leaf
- core
- distribution
- access
- firewalls

Device:
- hostname
- role
- model
- owner
- health
- alerts

Interface:
- ports
- LAGs
- VLANs
- errors
- utilization

Evidence:
- LLDP/CDP/BGP-LS/flow/syslog/config proof

## Rule

Do not show all details at all zoom levels.

Labels, ports, metrics, and evidence must progressively reveal.
