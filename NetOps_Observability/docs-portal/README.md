# Correlix Documentation Portal

Customer-facing product documentation for Correlix, built with [Docusaurus](https://docusaurus.io/).

The content is **task-oriented** — it explains how to configure and use each feature
step by step, from an operator's perspective (not the internals). It's modeled on
leading product docs (Datadog et al.) and anchored on the device-onboarding journey.

## Structure

- `docs/` — all content as portable Markdown (frontmatter: `title`, `sidebar_label`,
  `description`). The sidebar is **autogenerated** from the folder tree; each folder's
  `_category_.json` sets its label/order. Add a page = drop a Markdown file in the
  right folder.
- `docusaurus.config.js` — site config (title, navbar, footer, theme).
- `sidebars.js` — one autogenerated sidebar over `docs/`.
- `src/css/custom.css` — Correlix dark-first theme.

Because the content is plain Markdown, it can also be lifted into the marketing
website as it comes online.

## Develop

```bash
npm install
npm start          # dev server with hot reload → http://localhost:3000
npm run build      # production build → ./build
npm run serve      # serve the production build locally
```

Requires Node.js >= 18.

## Writing conventions

- One page = one task or feature. Lead with what it's for, then numbered steps, then verify.
- Use `<kbd>Section → Leaf</kbd>` for console navigation paths.
- Be honest about "—"/empty states; don't document features that don't exist yet.
- Cross-link generously with root-relative links (e.g. `/onboard-devices/overview`).

## Status
