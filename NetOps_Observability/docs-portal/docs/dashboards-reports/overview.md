# Dashboards & Reports

| Feature | Console path | What it's for |
| --- | --- | --- |
| **Home / Command Center** | <kbd>Dashboards → Home</kbd> | The operational control plane on first load |
| **Operations Overview** | <kbd>Dashboards → Operations Overview</kbd> | Fleet‑wide summary |
| **My Dashboard** | <kbd>Dashboards → My Dashboard</kbd> | Your personal board |
| **Dashboard List** | <kbd>Dashboards → Dashboard List</kbd> | The catalog of built‑in boards (device/interface/BGP/bandwidth/WAN) |
| **Reports** | <kbd>Dashboards → Reports</kbd> | Scheduled, generated reports |

## Scheduled reports

1. Go to <kbd>Dashboards → Reports</kbd>.
2. Create a report from a template (e.g. availability SLA, fleet summary).
3. Set the schedule and recipients.

Reports are generated on the schedule and delivered to the recipients you choose.
