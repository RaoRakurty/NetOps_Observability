# Log Search

Once devices are sending **[syslog](/send-data/syslog)**, search it at <kbd>Logs → Log Search</kbd>.

## Search

1. Go to <kbd>Logs → Log Search</kbd>.
2. Enter a query (free‑text and field filters — device, severity, message) and a time range.
3. Drill into any message; pivot to the device or a related event.

## Saved searches

Save a query you run often (<kbd>Logs → Saved Searches</kbd>) — e.g. "BGP neighbor down across the fleet" — to re‑run it in one click.

Everything is **tenant‑scoped** — you only search your own logs.
