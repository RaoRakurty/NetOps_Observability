# Explore Your Data

The **Data** zone is where you query the raw telemetry directly — for investigation, ad‑hoc analysis, or building a view.

| Plane | Console path | What it's for |
| --- | --- | --- |
| **Metrics** | <kbd>Metrics</kbd> | Query any metric series (Metrics Explorer) |
| **[Flows](/explore/flows)** | <kbd>Flows</kbd> | Traffic analytics, top talkers, app breakdown |
| **[Logs](/explore/logs)** | <kbd>Logs → Log Search</kbd> | Full‑text log search + saved searches |

Everything here is **tenant‑scoped** — you only ever query your own data.
