# October 2026

## New features

### Devices from your SD-WAN controller

Correlix now builds inventory from a controller connector as well as from
discovery: every device the controller reports gets one device record, stored
per integration and kept separate per tenant. The device page shows what vManage
reports about the device, including its chassis serial.

vManage depth grew too: fleet-wide tunnel, interface, device-health, counter and
certificate metrics; BFD, control-connection and tunnel state polled per device;
QoS, hardware health and audit-log changes; one identity per SD-WAN tunnel, with
recoveries clearing the matching alert; and canonical controller severities, so a
polled vManage outage opens an incident. vManage 20.x session login is supported.

- **Where:** Infrastructure → Devices; Administration → Integrations
- **Read next:** [Infrastructure](/infrastructure/overview)

### A redesigned Administration area

Administration is now seven groups in setup order, with one colour per group and
one page header. Discovery is one page (SNMP profiles, network scan, sensors and
coverage), RCA Tickets is one numbered flow from destination to delivery, and the
License page says each thing once.

- **Where:** Administration
- **Read next:** [Administration](/administration/overview)

### Iris opens docked

The Iris panel opens docked beside the page, in plain language, with a model
icon and the theme colour. You can float it over the page instead.

- **Where:** the **Iris AI** button at the foot of the sidebar
- **Read next:** [Iris](/iris-ai/overview)

## Improvements

- Every internal TLS certificate renews in the running service, with no restart.
- Device pages say where to turn a feature on, in plain words.
- Interface charts show device names, and the device picker works on the
  interface views.
- US English in everything a user reads ("License", not "Licence").
- CI runs only the checks a change needs, and proves it with a per-workflow gate.

## Fixes

- The platform's own alerts are visible to the platform only. Before, they could
  reach a tenant's scope.
- A metric query is bound to the caller's own tenant, and matcher values are
  escaped.
- Controller webhooks fail closed when their shared secret is not configured, and
  the controller lane verifies the tenant of every event.
- SNMP traps are attributed to the inventory device instead of being
  quarantined.
- The metrics push credential is never logged or stored by the collectors.
- The cluster-status health metric no longer reports a false RED after recovery.
