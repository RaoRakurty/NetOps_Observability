# Security & Compliance

Correlix tracks the security posture of your network devices alongside their health.

## What's in it

| Feature | Console path | What it's for |
| --- | --- | --- |
| **Vulnerability Management** | <kbd>Security → Vulnerability Management</kbd> | Known‑CVE exposure across the fleet |
| **Threat Detection** | <kbd>Security → Threat Detection</kbd> | Suspicious activity from logs/flows |
| **Compliance Monitoring** | <kbd>Security → Compliance Monitoring</kbd> | Configuration/compliance checks |

These read from the same onboarded telemetry — no separate agents. The more planes you've onboarded ([syslog](/send-data/syslog), [flows](/send-data/flows)), the more the security views can see.
