---
topic: admin.security-settings
question: What do these security settings apply to?
keywords: security settings, password policy, lockout, session rules, scope
---
Password rules, lockout and session limits for everyone in this scope — the
Provider realm, an organization or a tenant. They are scope-wide, not per
person: change them here and every account created or signing in under this
scope is governed by them. The settings that belong to one person — two-
factor, a temporary account — live on that user in the directory instead.
