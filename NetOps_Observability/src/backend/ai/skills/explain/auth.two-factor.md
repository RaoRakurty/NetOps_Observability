---
topic: auth.two-factor
question: What is two-factor authentication here?
keywords: two-factor, 2fa, mfa, one-time code, authenticator app, totp
---
A one-time code from an authenticator app, asked for after your password at
sign-in. You add this account to an app on your phone once — by scanning the
code on this card or typing the setup key — and from then on the app shows a
six-digit number that changes every thirty seconds. A password alone stops
being enough to reach the platform, so a stolen or reused password no longer
gets anybody in. The secret behind the code is shown only during enrolment and
never afterwards. This card only governs the platform's own accounts; a
federated account's second factor lives at your identity provider.
