---
topic: board.path-quality
question: What is Path quality?
keywords: path quality, latency jitter loss, probes
---
Path quality is the experienced network: round-trip time, jitter and loss
measured by active probes along real paths. It is what an application feels,
which is why it can be poor while every device on the path reports itself
healthy. Digital Experience holds the per-service view of the same
measurements.
