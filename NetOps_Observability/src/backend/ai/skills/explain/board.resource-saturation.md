---
topic: board.resource-saturation
question: What is Resource saturation?
keywords: resource saturation, headroom, cpu memory storage
---
Resource saturation shows where headroom is thinning: control-plane CPU,
memory, storage and temperature across the fleet. These are the pressures that
turn a working device into an unstable one before anything goes down, so they
are read as a trend rather than as a threshold. The panels drill into the
devices contributing most.
