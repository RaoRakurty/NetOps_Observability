---
topic: cloud.ingestion-status
question: What does ingestion status prove?
keywords: is data arriving, trust gate, per account region source
---
It is the trust gate for everything downstream: before any page claims cloud
application health or a cloud root cause, this one answers whether the data is
actually arriving, per account, per region, per source. A stale or absent
source here is the reason a health verdict elsewhere should not be believed.
