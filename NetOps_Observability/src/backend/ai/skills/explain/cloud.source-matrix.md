---
topic: cloud.source-matrix
question: How do I read the source matrix?
keywords: source matrix, per account region source, chips measured per provider
---
One row per account and region, one chip per source type. Each chip is
measured per provider rather than assumed: a source that is off reads off, and
a source nothing measures reads as not measured — never as a fabricated
"flowing". Hover a chip for its last sync, its volume, and the provider's own
error where one was reported.
