---
topic: compliance.no-check
question: What if a control has no check?
keywords: no check for this control, cannot evidence, control coverage
---
This platform has no check that produces evidence for that control, so it can
never pass or fail here. It is counted in the framework's scope and excluded
from the passing share, and the coverage figure on the framework card says how
many controls the platform can evidence at all. Controls it cannot evidence
need evidence from somewhere else — a process document, another tool — before
an auditor will accept them.
