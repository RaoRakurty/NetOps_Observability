---
topic: dem.briefing-data-class
question: Why could no briefing be built?
keywords: no briefing, evidence packet unavailable, data class
---
The AI briefing is built only from evidence classified as safe to leave the
platform. When every item on an incident is above that class, no packet can be
assembled and none is sent — the surface says so instead of quietly sending a
thinner one. The data classification is set under Administration.
