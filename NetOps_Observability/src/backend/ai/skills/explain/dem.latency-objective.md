---
topic: dem.latency-objective
question: What if I leave the latency objective empty?
keywords: latency objective, p95 objective, no objective
---
Leaving the p95 latency objective empty declares that this journey has no
latency objective, and none is invented for it. The journey is still measured
and its success rate still tracked; only the latency verdict is withheld. Set
a number later and it applies from that point.
