---
topic: dem.nothing-missing
question: Nothing is recorded as missing — is that reassuring?
keywords: nothing missing, missing evidence empty
---
Only when every source is reporting. Digital Experience records a source as
missing when it was expected and did not arrive; a source nobody wired is not
expected, so it is never missed. The Data Health tab is where you see which
sources are actually reporting, and it is the honest place to read this from.
