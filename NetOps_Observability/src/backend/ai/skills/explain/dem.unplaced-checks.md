---
topic: dem.unplaced-checks
question: Why are some checks not plotted?
keywords: unplotted checks, unplaced checks, missing site or application label
---
The heatmap is a grid of site by application, so a check carrying no site
label or no application label has no cell to sit in and is counted as
unplotted instead. That is a labelling gap, not a healthy result — the check
is still running and still scored. Add the labels on the Synthetics tab and it
appears in the grid.
