---
topic: flows.app-coverage
question: How much of the window did the application view name?
keywords: flow coverage, busiest pairs, catalogued address ranges, application naming, not every flow
---
Names come from the busiest source-to-destination pairs in the window, not
from every flow. The line states how many pairs were read and how many
catalogued address ranges were available to name them, so you can read the
table as the heaviest traffic rather than as the whole window. When no
catalogue is loaded the names come only from live signals, and when the
endpoint reports no coverage at all the screen says so instead of implying
completeness. Small conversations can therefore be absent from this table
while still present in Conversations.
