---
topic: flows.busiest-links
question: What does the Busiest links table on the Flows page show?
keywords: busiest links, link utilisation, traffic change, previous window
---
Each row is one link: an interface on one device, named from the device's own
interface list. In and Out are the flow volume that entered and left on that
interface in the window, as the devices reported it. Utilisation comes from the
interface counters, the busier direction now, in percent of the link speed; a
dash means the interface reports no speed. Change compares the window with the
one before it of the same length, and reads a dash when that is not known.
Select a row to see the link's traffic over time, its top talkers and any
problem that named the device in the window.
