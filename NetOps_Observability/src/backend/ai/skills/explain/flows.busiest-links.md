---
topic: flows.busiest-links
question: What does the Busiest links table on the Flows page show?
keywords: busiest links, link utilisation, traffic change, previous window, reads low
---
Each row is one link: an interface on one device, named from the device's own
interface list. In and Out are the flow volume that entered and left on that
interface in the window. Utilisation comes from the interface counters, busier
direction, in percent of the link speed; a dash means no reported speed. Change
compares the window with the one before it of the same length. A figure marked
≈ reads low: some of that router's flow records name no interface for that
direction; hover it for the share. Select a row to see the link's traffic over
time, its top talkers and any problem that named the device.
