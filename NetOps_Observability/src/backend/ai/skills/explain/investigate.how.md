topic: investigate.how
question: How do I work the Troubleshooting page?
keywords: whats wrong, troubleshooting page, start investigation, describe the problem, open cases, evidence disclosure
---
Pick the problem, read the answer, open the evidence if you want it.

The list holds every open case: the ones Correlix correlated on its own, and the
ones you opened by describing a symptom. If yours is not listed, describe it and
press Start investigation — that creates a real record, so escalation and the
rest of the actions work on it immediately.

The answer card names the cause when the evidence supports one, the layer it is
breaking at, who it affects and when it started. When nothing is confirmed it
says so rather than guessing.

Show the evidence opens what every lane found. A quiet lane still reports that
it looked and saw nothing.
