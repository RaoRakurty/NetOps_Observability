---
topic: iris.explain-correlation
question: What does Iris give me when I ask it to explain this problem?
keywords: explain this problem, grounded answer, evidence-cited, iris ai card, root cause
---
A grounded, evidence-cited explanation of this one correlation: the root cause
it reads from the evidence, the observations that support it, what is missing,
and a recommended next action. It is not a free-form chat about your network —
the backend retrieves this correlation's own tenant-scoped evidence first and
answers only from that, then lists the records it used as links you can click
back into. Every claim is meant to be checkable that way. When no model
provider is configured the answer is evidence-only, and the card says so rather
than improvising.
