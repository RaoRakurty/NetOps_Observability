---
topic: lane.no-run-yet
question: The lane has never run — what does that mean?
keywords: no run recorded, never assessed, lane never ran
---
The lane is enabled but has recorded no run, so nothing has been assessed. That
is different from having been assessed and found clean. Start a scan here, or
wait for the schedule; the row appears as soon as one run completes. Until then
every count on the Security pages is a count of nothing measured.
