---
topic: licence.install-verified
question: What happens if a licence is refused?
keywords: install licence, verified before written, refused document
---
The document is verified before anything is written. A licence the platform
will not accept is refused with the platform's own reason and never displaces
the one already in force — so a bad file cannot cost you a working licence.
Only when verification passes is the new document stored and the ceilings
recalculated.
