---
topic: page.active-alerts
question: What does the Active Alerts page show?
keywords: active alerts, alert episodes, alerts page
---
Active Alerts shows firing conditions folded into episodes. Repeated firings
of the same condition on the same resource collapse into one episode, so you
triage a problem once instead of once per notification. Each episode can be
acknowledged, assigned, muted, snoozed and annotated, and it keeps updating
while you work it. Correlated incidents — alerts grouped by cause — live on
the Command Center instead.
