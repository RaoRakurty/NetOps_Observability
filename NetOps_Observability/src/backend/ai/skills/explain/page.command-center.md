topic: page.command-center
question: What is the Command Center for?
keywords: command center, home page, control plane
---
The Command Center is the first screen of a shift. It answers four questions
in order: what is burning, who owns it, what is already ticketed, and what is
blocked waiting on evidence. The rows are correlation groups, not raw alerts,
so the queue is a list of causes to work rather than messages to read. Every
number on it filters the queue below, so a count and the rows it stands for
can never disagree.
