---
topic: path.golden
question: What is golden-path comparison?
keywords: golden path comparison, approved path, expected path, not configured
---
A golden path is the route this traffic is meant to take, recorded in advance
so a live path can be compared against it. Nothing is configured here yet, so
no comparison is made and none is implied — the path shown is simply the path
resolved. Recording a golden path turns every later trace into a difference
rather than a fresh reading.
