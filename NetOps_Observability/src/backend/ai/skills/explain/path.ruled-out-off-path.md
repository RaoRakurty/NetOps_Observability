---
topic: path.ruled-out-off-path
question: Why are these faults ruled out?
keywords: ruled out, off-path, not the cause, severity is not causality, discounted
---
These things did change in the same window, and some of them may look worse
than the thing that broke. They are still not the cause of this incident,
because they are not on the path between the affected source and destination:
traffic never touched them. Severity is not causality. Listing them is
deliberate — an operator who can see what the engine considered and set aside
can challenge it, and a fault that is off THIS path may still be worth fixing
on its own. Hover one to read the reason the engine gave for discounting it.
