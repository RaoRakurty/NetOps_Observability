topic: pipeline.legacy-board
question: What is the collection pipeline board for?
keywords: collection pipeline board, legacy troubleshooting board, pipeline or device, collector health
---
It is the old June troubleshooting board, and it answers exactly one question:
is the PIPELINE or the DEVICE at fault? The collector self-metrics it charts
keep reporting even when every device is unreachable, so the board stays useful
precisely when the device boards go dark. It stays reachable for one release
while operators move across; day-to-day troubleshooting now starts on the
Investigation surface, which asks what is wrong rather than which component is
broken, and runs the evidence lanes in parallel from there.
