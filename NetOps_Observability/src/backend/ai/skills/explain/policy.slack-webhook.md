---
topic: policy.slack-webhook
question: What is this webhook used for?
keywords: slack webhook, incoming webhook, tenant own channel
---
This tenant's own Slack incoming-webhook URL. It is used only by the Slack
incident policies below, so a message can only ever reach the channel you
point it at here. It is write-only: type a new URL to replace the stored one,
or leave it blank to keep it.
