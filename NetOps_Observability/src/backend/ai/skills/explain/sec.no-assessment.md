---
topic: sec.no-assessment
question: Why does every stage read zero?
keywords: no assessment yet, stages count zero, nothing measured
---
No assessment has run on this deployment yet, so every stage of the pipeline
counts zero because nothing was measured — not because the estate is clear.
Start a scan from the Security lane panel, or enable the lane so it assesses on
its schedule. Once one run finishes, the stages count what it found and the
coverage figure states how much of the estate it reached.
