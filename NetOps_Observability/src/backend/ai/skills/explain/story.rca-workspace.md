---
topic: story.rca-workspace
question: Where does an exposure story open?
keywords: rca workspace, opens the story, fourth evidence class
---
Each story opens in the RCA workspace — the same causality path, the same
ownership panel and the same export the network incidents use. That is
deliberate: security is a fourth evidence class inside one correlation engine,
not a separate product with its own console. Anything you can do to a network
incident there you can do to an exposure story.
