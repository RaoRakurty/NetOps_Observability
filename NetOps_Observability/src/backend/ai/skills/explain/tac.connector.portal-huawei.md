question: Why does Huawei need the portal, and what do I configure?
keywords: huawei support, huawei sr portal, huawei osm ticket, huawei enterprise tac
---
Huawei publishes no case API for enterprise or carrier networking. Huawei
Cloud's OSM does publish one, but it opens cloud tickets rather than
network-device TAC cases, so it is out of scope. Checked 2026-09-05; the
enterprise SR portal is JS-gated, so its field list and severity table are not
publicly retrievable and Correlix does not assume them. This path is chipped
Manual, never Ready: configuration cannot bring an API a vendor does not
publish. What it does bring is yours — the portal your contract routes you to, a
support mailbox, your support account, and the shape of a case number. Set those
on Administration → Ticket delivery.
