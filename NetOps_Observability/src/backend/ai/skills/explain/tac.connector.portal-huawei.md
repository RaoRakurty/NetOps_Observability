topic: tac.connector.portal-huawei
question: Why is Huawei a copy-and-paste path?
keywords: huawei support, huawei sr portal, huawei osm ticket, huawei enterprise tac
---
Huawei publishes no case API for enterprise or carrier networking. Huawei Cloud's
OSM does publish a service-request API, but it opens cloud tickets rather than
network-device TAC cases, so it is out of scope here. So Correlix prepares the
case text and the redacted bundle, and you open the service request at
support.huawei.com with the product, a problem description and the attachments.
The enterprise SR portal is JavaScript-gated, which means its exact field list
and severity table cannot be retrieved from outside — Correlix does not guess
them, and offers no severity scale for Huawei. A private or partner-only API
cannot be disproven from outside either. Checked 2026-09-05.
