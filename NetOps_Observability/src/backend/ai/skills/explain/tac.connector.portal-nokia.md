Nokia publishes no case API. NSP exposes five APIs — NSP REST, RESTCONF,
Kafka, NFM-P REST and NFM-P XML — and none opens a TSR; the developer portal
returns nothing for ticket, support case or TSR. Checked 2026-09-05. So this
path is chipped Manual, never Ready: configuration cannot bring an API a vendor
does not publish. What it does bring is yours — the portal your contract routes
you to, a support mailbox, your support account, and the shape of a case number.
Set those on Administration → Ticket delivery and the row reads Manual ·
configured. Nokia prefers the phone for outages and publishes no severity scale,
so none is offered.
