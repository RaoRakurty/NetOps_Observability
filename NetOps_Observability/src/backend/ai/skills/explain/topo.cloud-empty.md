---
topic: topo.cloud-empty
question: Why is the cloud canvas empty?
keywords: no cloud network, cloud discovery, vpc vnet discovery, cloud topology empty
---
Nothing has been discovered in the cloud domain yet. That is not a claim that
your cloud is empty — it is that no account has been connected, or discovery
has not run against one. Connect an AWS, Azure or GCP account under Data
sources and enable discovery; the VPC or VNet, subnet, route-table and gateway
graph appears on this canvas as it is found. A failed cloud read says so
separately, because "not discovered" and "could not be read" are different
answers.
