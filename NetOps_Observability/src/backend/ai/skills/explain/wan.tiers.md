---
topic: wan.tiers
question: What are the measurement tiers?
keywords: measurement tier, five tier ranking, t1 t5, measured by, source ranking
---
Five sources can report the same link, and they are ranked by how close each
sits to what a user actually feels. Application measurement ranks first, then
an active path probe, then the device's own timing, then passive observation of
real traffic, then flow records. The winning tier is shown per row with the
method that produced it, so two rows with the same latency are still
comparable. A row with no measurement shows a dash — never a number borrowed
from a lower tier.
