---
topic: wifi.remediation
question: Where do wireless remediation proposals come from?
keywords: wireless remediation, proposal from evidence, approve reject execute
---
A proposal is only created from evidence that took part in a confirmed
incident, so nothing here is a suggestion the platform invented. Each one names
a single target, is approved or rejected by a named person with a reason on the
record, and runs only when someone executes it. Approval does not run anything.
Execution goes through the vendor controller, and where no controller write is
available the action records itself as refused rather than reporting a change
it did not make.
